# π0.5：开世界泛化的异构数据共训练

> π0.5 把机器人轨迹、高层子任务、人类口头指令、网页多模态数据放进同一个训练配方，使端到端机器人能进入从未见过的家庭执行 10–15 分钟家务。

## 1 背景与问题

π0 已能完成灵巧任务，但主要依赖训练分布内的任务和场景。家庭环境的特点是：

- 每个家的物体、抽屉、台面、光照都不同；
- 用户指令模糊且多样；
- 长程家务需要连续规划几十个子任务；
- 单靠机器人演示无法覆盖世界知识。

π0.5 的核心问题是：如何把非机器人数据中的语义与空间知识转化为机器人可用的高层和低层能力。


---

## 2 核心贡献

1. 提出异构数据 co-training 配方：移动机器人、多环境非移动机器人、实验室跨实体数据、高层子任务、多模态网页数据；
2. 同时预测高层文本子任务与低层动作块，形成统一的高低层 VLA；
3. 在预训练阶段使用 FAST 离散动作 token，在后训练阶段加入 Flow Matching 连续动作专家；
4. 引入 verbal instruction 与网页问答、检测、定位任务，强化语言和空间 grounding；
5. 首次展示端到端学习系统在全新真实家庭中完成长程、灵巧家务。


---

## 3 核心原理与方法详解

π0.5 的统一目标可抽象为：

$$
p_\theta(\hat{\ell}_{t+1}, a_{t:t+H}\mid o_t, \ell),
$$

其中 $\ell$ 是总任务，$\hat{\ell}_{t+1}$ 是预测子任务，$a_{t:t+H}$ 是动作块。

训练包含三类输出：

1. **高层推理**：预测下一个子任务；
2. **离散动作**：用 FAST tokenizer 压缩动作块，作为文本 token 自回归预测；
3. **连续动作**：action expert 用 Flow Matching 输出连续动作。

训练损失形式上可写成：

$$
\mathcal{L}
=
\mathcal{L}_{\text{text}}
+
\alpha \mathcal{L}_{\text{FAST}}
+
\mathcal{L}_{\text{Flow}}.
$$

不同表示之间使用注意力掩码隔离，避免离散动作 token 与连续噪声动作互相污染。推理时先输出子任务，再以该子任务为条件生成低层动作。


---

## 4 数据与训练

**数据源**：

- **MM（移动操作机器人）**：约 400 小时家庭任务；
- **ME（多环境非移动机器人）**：扩大家庭和物体多样性；
- **CE（实验室跨实体）**：包含 OXE 等开源数据；
- **HL（高层子任务）**：对轨迹段落标注下一步语义动作；
- **WD（网页数据）**：caption、VQA、物体定位、室内场景数据；
- **VI（verbal instruction）**：后训练阶段的人类口头子任务。

**两阶段训练**：

1. 预训练：统一 token 表示 + FAST 动作，训练 280k steps；
2. 后训练：加入 Flow Matching action expert，混合机器人、网页、高层子任务和口头指令，再训练 80k steps；
3. 动作归一化到 $[-1,1]$，低维机器人零填充到统一动作维度；
4. 输出 18–19 DoF 的关节、底盘、升降等动作，控制约 50 Hz。


---

## 5 实验、结果与解读

π0.5 在 3 个新厨房和 3 个新卧室中评估“物品进抽屉、洗衣篮、餐具进水槽”等任务。论文显示：

- 在完全未见家庭中可完成长程任务，时长约 10–15 分钟；
- 相比 π0，语言跟随和任务成功率大幅提升；
- 去掉网页数据、高层子任务或跨实体数据会明显损害泛化；
- 显式预测子任务优于只做隐式低层推理；
- 口头指令数据能提升高层策略质量，GPT-4 作为高层规划器不如训练出的子任务策略。


---

## 6 精读要点与实践建议

- **开世界泛化不是单靠更多真机数据**，而是让机器人、语言、网页、人类指令共享表征；
- **高层子任务是强正则**：它把长程家务分解成可复用技能；
- **混合动作表示**说明离散 token 利于快速训练，连续 Flow Matching 利于精细推理；
- **网页任务要选得像机器人**：物体定位、检测、caption、室内场景比随机网页文本更有用；
- **实践建议**：做家庭机器人时，环境数量和指令多样性可能比单一环境演示数量更重要。


---

## 7 局限与后续影响

- 家庭中的长尾物体和空间布局仍会失败；
- 任务范围主要集中在整理清洁，不等于任意家务；
- 高层子任务标注和口头指令数据仍有成本；
- 网页数据与真机动作存在语义到物理的鸿沟；
- 成功率和吞吐仍需 RL 与部署数据改进，这直接引出 π*0.6。
