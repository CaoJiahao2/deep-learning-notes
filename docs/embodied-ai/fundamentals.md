## 1 概述 {#1}

具身智能（Embodied AI / Embodied Intelligence）指智能体以**实体形态**（机器人、移动平台等）存在于物理环境中，通过传感与执行闭环完成任务的智能形态。与纯语言或纯视觉智能的根本区别在于：它必须与物理世界形成**闭环交互**——感知当前状态、做出决策、发出动作，再根据环境反馈更新感知，如此往复。

- **纯语言智能**（LLM）：输入输出均为符号序列，不接触物理因果链；
- **纯视觉智能**：理解图像/视频，但不产生改变世界的动作；
- **具身智能**：输出会真实改变世界状态，并被新一轮观测所捕获。

与 LLM / MLLM 的关系是互补而非替代：LLM 提供常识、语义理解与长程推理，Vision-Language-Action（VLA）模型则把这种高层认知**落到关节级别的动作**。可以粗略地把具身智能看作 "MLLM 的大脑 + 机器人的身体"。

典型任务包括：

1. **机器人操作（Manipulation）**：抓取、放置、装配、工具使用、双手协作；
2. **导航（Navigation）**：在室内外环境中自主移动、避障、寻路；
3. **移动操控（Mobile Manipulation）**：边走边操作，如打开柜门取物、清理桌面。

本章是具身智能部分的坐标系：第 2 节建立问题建模（POMDP 与信念状态、观测模态、动作空间），第 3 节详细对比三种学习范式，第 4 节讨论贯穿所有方法的关键概念与主要挑战。后续章节都在这个框架内展开：策略学习方法见 [模仿学习与策略学习](./policy-learning.md)，VLA 架构与动作表示见 [VLA 模型](./vla.md)，VLM 基础见 [大语言模型与多模态大模型综述](../llm-mllm/survey.md)。

## 2 问题建模 {#2}

具身智能通常被建模为**马尔可夫决策过程（MDP）**或更一般的**部分可观马尔可夫决策过程（POMDP）**，因为机器人只能通过带噪传感器间接估计真实状态。

### 2.1 MDP / POMDP 要素

- 状态 $s_t$：环境与机器人的完整描述，通常不可直接获取；包含视觉观测（RGB-D 帧）、本体感觉（关节角度、力矩、末端位姿）等。
- 观测 $o_t$：传感器读数，$o_t \sim \Omega(s_t)$，$\Omega$ 为观测函数。
- 动作 $a_t$：可执行指令，如关节力矩 $\tau_t$、末端速度 $\dot{x}_t$、夹爪开合量，或离散化的动作 token。
- 转移 $p(s_{t+1} \mid s_t, a_t)$：环境动力学，通常未知。
- 奖励 $r_t = r(s_t, a_t)$：任务完成度的标量反馈。
- 策略 $\pi_\theta(a_t \mid o_t)$：由参数 $\theta$ 决定的（随机）策略。

注意策略只直接接触 $o_t$ 与 $a_t$，从不接触 $s_t$——这正是"部分可观"的含义，也是下面信念状态与滤波要解决的问题。

### 2.2 策略目标

目标是找到使折扣累积回报最大的策略：

$$\max_\theta\; \mathbb{E}_{\pi_\theta}\left[\sum_{t=0}^{T}\gamma^t r_t\right]$$

其中 $\gamma \in [0,1)$ 为折扣因子。在模仿学习设定下并不显式使用奖励，而是从专家演示中直接回归策略；两者最终都希望逼近一个好的回报。

### 2.3 POMDP 的近似求解

由于真实状态不可观测，Agent 通常用**历史观测与动作的函数**作为策略条件：

$$\pi_\theta(a_t \mid o_1, a_1, \dots, o_t)$$

实现上可使用循环网络（维护隐状态）或 Transformer（读完整历史）。当观测足以近似状态时（如 RGB-D + 本体感觉齐全），可视为"近似 MDP"。更严格的做法是把"历史"压缩为一个充分统计量——**信念状态（belief state）**，见下节。

### 2.4 信念状态与滤波

信念状态是给定全部历史后对当前状态的 posterior 分布：

$$b_t(s) = p(s_t = s \mid o_1, a_1, o_2, a_2, \dots, o_t)$$

贝叶斯滤波给出它的递推更新：

$$b_{t+1}(s') = \eta\, \Omega(o_{t+1} \mid s', a_t) \sum_{s \in \mathcal{S}} T(s' \mid s, a_t)\, b_t(s)$$

其中 $T(s' \mid s, a) = p(s_{t+1} = s' \mid s_t = s, a_t = a)$ 为转移核，$\eta$ 为归一化常数。直观读法：先用上一时刻信念与转移模型做**预测**（求和项），再用新观测做**修正**（乘以观测似然）。

**信念 MDP 等价**：POMDP 等价于一个以信念 $b$ 为（连续）状态的 MDP，转移由上式给出，策略与值函数都定义在信念上：

$$V^*(b) = \max_{a}\left[\sum_{s} b(s)\, r(s, a) + \gamma \sum_{o'} \Pr(o' \mid b, a)\, V^*(\tau(b, a, o'))\right]$$

**何时必须显式维护信念**：当任务本质上依赖不可见信息时，反应式策略 $\pi(a \mid o_t)$ 会系统性失败——抓取被手遮挡的物体（需要从历史帧推断物体位姿）、推抽屉时看不到内部状态（需要从阻力反馈推断）、多物体追踪中目标短暂离开视野。这类任务的策略必须记忆，区别只在"显式滤波"还是"网络隐式记忆"。

**在深度学习中的用途**：它解释了"为什么 RNN/Transformer 策略有效"——它们就是在**学习**信念的近似（隐状态即学到的 belief）；也解释了"什么时候可以退化为反应式策略"——当 $b_t$ 集中在真实状态附近（观测信息量大）时，$\pi(a \mid b_t) \approx \pi(a \mid o_t)$。

**滤波器实现谱系**：

| 方法 | 信念表示 | 适用条件 | 机器人中的例子 |
|---|---|---|---|
| Kalman 滤波 / EKF | 高斯（均值 + 协方差） | 线性（或可线性化）+ 高斯噪声 | 关节状态估计、SLAM 位姿 |
| 粒子滤波 | 加权粒子集 $\{(w^{(i)}, s^{(i)})\}_{i=1}^{N}$ | 任意分布、多峰 | 全局定位、目标跟踪 |
| 学习式隐状态（RNN/Transformer） | 神经网络隐向量 | 无法手写动力学模型 | 视觉操作策略、world model 的 RSSM |

深度学习路线通常不显式计算 posterior，而是让网络从 $(o_{t-k}, \dots, o_t)$ 或循环隐状态中隐式编码信念，训练信号来自任务回报或重建损失。世界模型视角详见 [世界模型](./world-model.md)，RL 基础见 [强化学习](../training/reinforcement-learning.md)。

### 2.5 观测模态

$o_t$ 的具体内容决定了任务的信息基础与难度：

| 模态 | 典型内容 | 典型频率 | 信息与局限 |
|---|---|---|---|
| RGB(-D) 相机 | 场景外观、物体位姿、深度 | 15–60 Hz | 遮挡、光照敏感、视野外不可见 |
| 本体感觉（proprioception） | 关节角/角速度/力矩、末端位姿、夹爪状态 | 100–1000 Hz | 精确可靠，但"看不见"外部世界 |
| 触觉 | 接触位置、压力分布、滑移 | 100–1000 Hz | 对精细操作关键，但传感器脆弱、覆盖面小 |
| 力/力矩（F/T） | 末端接触力、负载 | 数百 Hz | 反映物理交互，只覆盖安装部位 |
| 语言指令 $\ell$ | 任务目标与约束 | 一次性 | 有歧义、不含执行细节 |

两个工程事实必须面对：**频率失配**（视觉几十 Hz、伺服控制上百 Hz，低频观测驱动高频控制 → 动作分块，见 4.1）与**部分可观测的物理来源**（遮挡、噪声、标定误差、传感延迟）。观测设计原则：优先补齐"任务不可缺"的信息（如精确插入需要力/触觉反馈），而非堆砌模态数量。

### 2.6 动作空间表示

$a_t$ 如何定义，直接决定策略的学习难度与跨本体可迁移性：

| 表示 | 形式 | 优点 | 缺点 | 代表 |
|---|---|---|---|---|
| 关节空间 | $a_t \in \mathbb{R}^{d_j}$，各关节目标位置/速度/力矩 | 无需逆运动学、动力学一致、灵巧手必需 | 与形态绑定、跨本体难迁移、维度高 | ACT/ALOHA、灵巧手策略 |
| 笛卡尔（末端）空间 | $a_t = [\Delta p_t;\, \Delta \omega_t;\, g_t] \in \mathbb{R}^{7}$（位置增量 + 姿态增量 + 夹爪） | 形态无关（由 IK 落到具体机器人）、任务语义强 | 需逆运动学、可能奇异/越界、无法表达全身协同 | Diffusion Policy（末端增量版）、多数 VLA |
| 离散 action token | 每维离散为 $B$ 个 bin，动作块即 token 序列 | 复用 LLM 解码器与词表、可自回归建模 | 量化误差、精确控制难、bin 数随维度爆炸 | RT-1、RT-2、OpenVLA |
| 连续生成式 | diffusion / flow matching 动作头 | 建模多模态分布、推理步数可控 | 训练与推理成本较高 | pi0、RDT-1B |

选择经验：**抓取类任务优先末端增量空间**（语义清晰、跨实体）；**高动态/全身任务用关节空间**；**以 VLM 为骨干时在离散 token 与连续生成式头之间二选一**（详见 [VLA 模型](./vla.md) 的"动作输出路线"）。动作如何被执行层消费（IK、阻抗控制、插值）见 [机器人控制与运动规划](./control.md)。

## 3 三种范式对比 {#3}

### 3.1 范式概览

| 范式 | 表示 | 优点 | 局限 |
|---|---|---|---|
| 基于规则控制 | PID / 运动学规划 / 状态机 | 可解释、稳定、可验证 | 难以泛化到非结构化场景 |
| 学习式（经典 RL） | $\pi_\theta(a \mid s)$，奖励驱动 | 可发现新策略、自适应 | 样本效率低、真机探索代价高 |
| 端到端 VLA | $\pi_\theta(a \mid o, \ell)$，条件于语言 | 跨任务泛化、利用大规模预训练 | 黑箱、数据昂贵、实时性约束 |

范式演进的主线是：**从手工设计规则 → 从数据中学习 → 从大规模多模态预训练中迁移**，使得策略具备语言可指令性与跨任务泛化能力。学习式路线内部又分为三条支线，下面分别展开。

### 3.2 端到端强化学习

直接在 MDP/POMDP 目标上优化策略。策略梯度定理给出（$x_t$ 统一表示状态、观测或信念）：

$$\nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta}\left[\sum_{t=0}^{T} \nabla_\theta \log \pi_\theta(a_t \mid x_t)\, A_t\right]$$

其中 $A_t$ 为优势函数。特点：**不需要演示，但需要海量交互与可验证的奖励**——真机上百万步探索既昂贵又不安全，因此端到端 RL 几乎总与仿真绑定（再面对 Sim-to-Real gap）；奖励设计不当时还会出现 reward hacking。代表工作：QT-Opt（真机抓取）、DayDreamer（learned world model + latent RL）。现状：纯端到端 RL 更多用于仿真任务与后训练阶段（在 BC/VLA 之上用 RL 微调）。方法基础见 [强化学习](../training/reinforcement-learning.md)，仿真训练见 [Sim-to-Real 与仿真器](./sim2real.md)。

### 3.3 模仿学习

从专家演示 $\mathcal{D} = \{(o_i, a_i)\}$ 监督学习策略：

$$\mathcal{L}_{\text{BC}}(\theta) = \mathbb{E}_{(o,a)\sim\mathcal{D}}\left[\|a - \pi_\theta(o)\|^2\right]$$

特点：**样本效率高**（数百条演示即可学一个任务）、无需奖励、部署简单；但能力上限是专家水平，且有两个顽疾——**协变量偏移**（策略偏离专家轨迹后进入未见状态，误差雪崩）与**分布坍缩**（MSE 回归会把多模态动作平均成无效均值）。对策：DAgger、Diffusion Policy、动作分块。展开见 [模仿学习与策略学习](./policy-learning.md)。

### 3.4 VLA 与分层范式

VLA 把预训练 VLM 作为骨干，条件于语言与视觉直接输出动作块：

$$a_{t:t+H} = \pi_\theta(o_{\le t}, \ell)$$

核心赌注是**互联网级预训练知识可迁移到控制**（物体语义、物理常识、任务规划）。分层/双系统变体把"慢思考"（VLM 规划，约 1 Hz）与"快行动"（技能策略，10–100 Hz）分离：高层把指令拆成子目标序列，低层技能负责执行。架构与训练细节见 [VLA 模型](./vla.md)，分层规划见 [具身智能前沿专题](./frontier.md)，VLM 基础见 [大语言模型与多模态大模型综述](../llm-mllm/survey.md)。

### 3.5 详细对比

| 维度 | 端到端 RL | 模仿学习（BC 系） | VLA 端到端 | VLA 分层（双系统） |
|---|---|---|---|---|
| 数据需求 | 奖励函数 + 数百万步交互（多为仿真） | 每任务数百–数千条专家演示 | 大规模多任务演示 + 互联网预训练语料 | 技能库演示 + 少量高层示例 |
| 样本效率 | 最低 | 较高（演示信息密度大） | 演示利用率高，但预训练成本极高 | 高层少样本，低层复用既有技能 |
| 泛化能力 | 受限于奖励与训练分布 | 任务内泛化，新任务需重新采集 | 跨任务、语言条件泛化最强 | 受技能库覆盖限制，但可组合 |
| 部署难度 | 需交互闭环，安全难保证 | 低（单次前向） | 模型大、延迟高，需量化/蒸馏 | 系统复杂：两层协同与接口设计 |
| 典型失败 | reward hacking、不安全探索 | 分布外雪崩、多模态均值化 | 幻觉动作、精细操作不足 | 高层规划错、技能边界误判 |
| 代表工作 | QT-Opt、DayDreamer | BC、DAgger、ACT、Diffusion Policy | RT-2、OpenVLA、pi0 | SayCan、Helix、GR00T N1 |

没有银弹，**数据预算基本决定范式**：演示充足用模仿学习；有仿真器且奖励可验证就加 RL；追求跨任务语言泛化上 VLA。实践中最常见的是组合拳：BC/预训练打底 + RL 后训练提升成功率 + 高层规划器扩展任务范围。

一个具体的组合示例：先在互联网视频与多机器人演示上预训练 VLA（3.4），用仿真 RL 微调提升抓取成功率（3.2），部署时由 VLM 规划器把"收拾厨房"拆成 20 个子任务（4.4）——三条范式各司其职，而非互相替代。

## 4 关键概念 {#4}

### 4.1 动作分块 (Action Chunking)

为降低高频控制下的延迟与累计误差，现代 VLA 通常一次预测未来 $H$ 步动作：

$$a_{t:t+H} = \pi_\theta(o_t, \ell)$$

随后用执行窗口内若干步（或加平滑/低通滤波）发送给机器人。执行窗口与重规划频率需要折中：窗口太长接近开环、难以应对扰动；太短则推理延迟主导控制频率。

### 4.2 跨实体泛化 (Cross-Embodiment)

不同机器人形态（单臂、双臂、夹爪、灵巧手）共享同一策略或表征。常见做法：

- **统一动作空间**：把不同机器人的动作投影到同一空间（如 7-DoF 末端 + 1-DoF 夹爪）；
- **形态 token**：把"机器人体型"也作为输入 token，让策略适配。

**Embodiment gap 从哪来**：

- **运动学差异**：关节数、臂长、工作空间（UR5 与 Franka 的同一"末端增量"含义并不相同）；
- **动力学差异**：负载能力、速度/加速度限制、反向可驱动性；
- **传感器布置**：相机数量、位姿与视野，有无触觉/力传感；
- **控制接口**：位置/速度/力矩控制模式、频率上限、夹爪自由度（1-DoF 平行夹爪 vs 20-DoF 灵巧手）。

**Morphology 迁移策略**：

1. **统一动作语义**：所有机器人投影到共享末端增量空间（RT-X / Open X-Embodiment 路线）；
2. **形态 token**：把机器人体型编码为输入 token，让策略学会"按形态解释动作"；
3. **人体到机器人的重定向（retargeting）**：把互联网人类视频转成机器人动作轨迹，作为弱标签预训练数据，缓解真机演示稀缺；
4. **形态随机化**：仿真中随机化连杆长度与关节配置，迫使策略学习形态无关表征。

跨实体数据与训练细节见 [VLA 模型](./vla.md) 与 [数据集与数据采集](./data.md)。

### 4.3 Sim-to-Real

仿真训练 + 真机部署的范式，需要弥合 Sim-to-Real gap，详见 [Sim-to-Real 与仿真器](./sim2real.md)。

### 4.4 长程任务分解

对"做早餐"这种长程任务，单一策略难以端到端完成。常用"分层规划"：

- **高层**：LLM/VLM 把任务拆为子目标序列（"开冰箱 → 取鸡蛋 → 煎蛋 → …"）；
- **低层**：每个子目标由专门的 VLA 策略执行。

这条思路的代表性工作见 [具身智能前沿专题](./frontier.md) 的"分层规划"小节。

### 4.5 具身智能的主要挑战

**（1）数据瓶颈**。真机遥操作演示昂贵（每条演示需要数分钟人工），仿真数据有 gap，互联网视频缺少动作标签且 embodiment 不同。可行路线是"仿真 + 遥操作 + 视频预训练 + 部署数据回流"的数据飞轮，详见 [数据集与数据采集](./data.md)。

**（2）安全**。学习策略的探索动作可能损坏物体或伤人。工程化的做法：把关节限位、力矩上限、速度上限作为**执行层硬约束**（独立于学习策略之外）；部署 rule-based 安全监视器，可随时否决策略动作；真机部署前在仿真中做压力测试与动作包络检查。

**（3）延迟与算力**。控制回路预算 = 相机曝光与传输 + 模型前向 + 通信 + 伺服执行。视觉策略前向往往只能跑到 5–50 Hz，而机械臂伺服需要数百 Hz——动作分块 + 执行层高频插值是标准解法；模型侧依赖量化与蒸馏，见 [模型压缩与量化](../deployment/model-compression.md)。

**（4）长程任务**。千步级任务中误差逐步累积、回报信号遥远（信用分配难）、子任务状态需要跨步骤追踪。分层分解（4.4）+ 显式状态检查点 + 中途重规划 + 记忆机制是当前主要的缓解手段；如何评测长程任务见 [具身智能评测基准](./evaluation.md)。

这四个挑战相互纠缠：数据稀缺限制了泛化，泛化不足放大安全风险，安全约束又反过来约束探索与数据采集。后续各章（[数据](./data.md)、[Sim-to-Real](./sim2real.md)、[评测](./evaluation.md)）分别拆解其中一环。
