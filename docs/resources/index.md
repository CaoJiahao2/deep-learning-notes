## 使用建议

1. **数据集选择先看原则**：[常用数据集](./datasets.md) 的「选择原则」小节讨论数据泄漏、许可证与污染检测，选基准前先读。
2. **学习资源按阶段取用**：[学习资源](./learning-resources.md) 按入门/进阶/专题分层，不必贪多，每个阶段挑 1-2 门课精读即可。
3. **求职早准备**：[大模型求职指南](./llm-career-guide.md) 的技术栈清单可反向用于查漏补缺。
